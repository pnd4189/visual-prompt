# visual-prompt

Tạo prompt ảnh + video 4K cinematic từ file truyện tiên hiệp / võ hiệp tiếng Việt
để làm video audio YouTube.

## Cài đặt nhanh

**Linux / macOS:**
```bash
bash setup.sh
```

**Windows:** `setup.bat` (admin/Dev Mode) — xem [antigravity/INSTALL.md](antigravity/INSTALL.md).

## Dùng

```
/visual-prompt <input.txt>
```

Output: 2 file `_image_prompts.txt` + `_video_prompts.txt` cạnh file input.
Paste từng block vào Gemini / Qwen / ChatGPT (ảnh) hoặc Veo3 / Seedance (video).
